# GED By DZ

- Stack utilisateur : Next.js App Router, Node.js, PostgreSQL, Tailwind CSS et Prisma. TypeScript pour le code applicatif.
- Un commit après chaque étape vérifiée. Ne jamais committer `.env`, mots de passe, données réelles, modèles PDF ou fichiers générés.
- Le dépôt PHP historique est séparé, dans `../ged`. Ne pas supprimer ni modifier ses données pendant la migration.
- Préserver toutes les pages, dimensions, orientations et proportions des PDF sources. Aucune mise au format A4 implicite.
- Autorisations côté serveur : administrateur pour modèles, dossiers, utilisateurs et paramètres ; documents limités à leur propriétaire hors administrateur.
- Vérifier typecheck, tests et build avant de publier un jalon.
